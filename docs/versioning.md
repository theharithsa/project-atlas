# Versioning and provenance

Project Atlas uses semantic versions for GitHub releases. The portfolio API identifies its JSON shape with `schemaVersion`. The first source release is `0.1.0` and the feed schema is `1`. [Changelog](../CHANGELOG.md)

GitHub generated this repository from App Launchpad template version `1.14.2`, commit `2e3162b9988a0dec0ec0c1ea12da2e22a5c989fa`. Its initial Git tree matches that source revision. The [project record](../project.json) stores the same provenance. The repository retains App Launchpad’s delivery skills, service registry, issue intake and checked pull request workflow. The product has its own Firebase frontend, feed, documentation and tests. [Upstream template revision](https://github.com/theharithsa/app-launchpad-template/tree/2e3162b9988a0dec0ec0c1ea12da2e22a5c989fa)

Adopt future template changes selectively through an issue-linked PR. Compare the current and proposed upstream commits, preserve the product’s services and settings, and update the recorded template revision after validation.
